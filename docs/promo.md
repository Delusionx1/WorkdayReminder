## 版本一 · 精简（配一张悬浮窗截图）

假期该不该给客户发消息？这个问题终于不用靠猜了。

做了个小工具「工作日提醒器」：屏幕右上角一个半透明小窗，实时告诉你**现在能不能联系客户**——法定节假日、调休上班日、午休、下班时间全都算好，节前最后一个工作日下午还会提醒你收尾。

- 完全免费，没有会员、没有内购
- 全部代码开源（MIT），一行不少，1100 行一个文件
- 无广告、无捆绑、无后台常驻、不上传任何数据
- 可二次开发：改判断逻辑、换界面、接公司系统，随便改

Windows 免安装，下载双击就能用：<https://github.com/Delusionx1/WorkdayReminder>

## 版本二 · 故事（长文案）

前阵子又在春节给客户发了条"方案您看下"——发完才想起来人家在过年。
于是花了个周末，给自己写了个小工具，顺手开源了。

「工作日提醒器」：屏幕右上角一个半透明小窗，只干一件事——告诉你**现在到底能不能联系客户**。

- 法定节假日、调休上班日、周末，按国务院安排算
- 再叠加客户上下班、午休时间，精确到"现在"
- 节前最后一个工作日下午提醒你收尾，假期结束第一天提醒你恢复跟进
- 自己请的年假、客户公司的特殊安排，写一行就能覆盖

三个原则：

- 🆓 免费，永久免费，没有会员没有内购
- 📖 全代码开源（MIT），读得完也改得动
- 🚫 无广告、无捆绑、无后台上传，除了拉一次节假日数据，不联网

Python + PySide6 写的，Windows 免安装版直接下：<https://github.com/Delusionx1/WorkdayReminder>
同行要是用得上，欢迎提 issue，也欢迎自己 fork 改成你们公司的版本。
